# Smart 2W Powertrain

ESP32-based Smart Electric Two-Wheeler Powertrain integrating BLDC motor control, Battery Management System (BMS), GPS tracking, Bluetooth communication, IoT monitoring, and optimized power distribution for efficient and reliable electric mobility.

---

## Project Overview

This project focuses on designing a low-cost intelligent electric two-wheeler powertrain capable of monitoring battery health, controlling motor performance, tracking vehicle location, and providing real-time operational data.

The system combines embedded hardware with IoT technologies to improve vehicle efficiency, safety, and reliability.

---

## Features

- ESP32-based control system
- BLDC motor speed control
- Battery Management System (BMS)
- GPS location tracking
- Bluetooth communication
- IoT data monitoring
- Buck-Boost power regulation
- Fault detection system

- Real-time sensor monitoring
